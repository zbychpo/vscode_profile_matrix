# Profile Extension Matrix

VS Code のローカルプロファイルごとに、インストール済み拡張機能を一覧で比較・管理する拡張機能です。プロファイルごとの構成を横断して確認し、必要な拡張機能を追加または削除できます。

## 主な機能

- 既定プロファイルとカスタムプロファイルの拡張機能をマトリクスで表示
- セルから対象プロファイルへの拡張機能の追加・削除
- 拡張機能名、表示名による絞り込み検索
- 拡張機能の詳細ページを開く
- Marketplace の最新バージョンと比較した `更新あり` の表示
- Marketplace で非推奨となっている拡張機能の表示
- プロファイル名から VS Code のプロファイル切り替え画面を開く

## インストール

1. VS Code を開きます。
2. Activity Bar の **Extensions** を開きます。
3. `Profile Extension Matrix` を検索します。
4. **Install** を選択します。
5. インストール後、Activity Bar の **Profile Extensions** アイコンを選択します。

コマンドパレットから **Profile Extension Matrix: Open** を実行して開くこともできます。

## 使い方

### 拡張機能を確認する

**Profile Extensions** ビューを開くと、行に拡張機能、列にプロファイルが表示されます。検索欄には拡張機能 ID または表示名を入力できます。

- 緑のチェックマーク: そのプロファイルで拡張機能が有効です。
- `+`: そのプロファイルには拡張機能がありません。
- `更新あり`: インストール済みバージョンより新しいバージョンが Marketplace にあります。これは状態表示であり、この拡張機能から更新は行いません。
- `非推奨`: Marketplace で非推奨に指定されている拡張機能です。

### プロファイルへ追加する

1. 追加したい拡張機能の行を探します。
2. 対象プロファイル列の `+` を選択します。
3. 確認ダイアログで **追加** を選択します。
4. 処理完了後、一覧が自動的に更新されます。

### プロファイルから削除する

1. 削除したい拡張機能の行を探します。
2. 対象プロファイル列のチェックマークを選択します。
3. 確認ダイアログで **削除** を選択します。
4. 処理完了後、一覧が自動的に更新されます。

削除は選択したプロファイルからのみ行われます。拡張機能を使用している他のプロファイルには影響しません。

### 詳細を開く・プロファイルを切り替える

- 拡張機能名を選択すると、その拡張機能の VS Code 詳細ページを開きます。
- 列見出しのプロファイル名を選択すると、VS Code のプロファイル切り替え画面を開きます。
- ツールバーの **更新** を選択すると、表示内容を再読み込みします。

## 必要条件

- VS Code Desktop 1.133 以降
- ローカルに作成された VS Code プロファイル
- 拡張機能の追加・削除時に VS Code の `code` CLI を実行できる環境
- 更新状況の確認時に Visual Studio Marketplace へアクセスできるネットワーク接続

## 制約と注意事項

- VS Code Desktop のローカルプロファイルのみが対象です。VS Code for the Web、Remote Development 環境、リモート側の拡張機能は対象外です。
- プロファイルの一覧と拡張機能の状態は、ローカルの VS Code 保存データから読み取ります。VS Code にプロファイルを横断して管理する公開 API はありません。
- 追加・削除は、VS Code CLI を使用して実行します。確認ダイアログを必ず表示します。
- `更新あり` は Marketplace の最新バージョンとの比較結果です。ネットワーク状況や Marketplace 側の情報により表示されない場合があります。
- 一時プロファイルは一覧に含めません。環境によってはプロファイル名が `既定` として表示される場合があります。

## データとネットワークアクセス

この拡張機能は、ローカルの VS Code プロファイル情報とインストール済み拡張機能のメタデータを読み取ります。更新状況と非推奨状態の確認のため、拡張機能 ID を Visual Studio Marketplace API に送信し、Microsoft が提供する Marketplace の公開情報を取得します。利用状況や個人情報を独自のサーバーへ送信することはありません。
